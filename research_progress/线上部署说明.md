# 线上部署说明

## 1. Supabase

在 Supabase SQL Editor 执行 `schema.sql`。执行后将 Project URL 和 anon/public key 填入 `config.js`：

```js
window.PROGRESS_CONFIG = {
  supabaseUrl: "https://你的项目.supabase.co",
  supabaseAnonKey: "你的 anon public key"
};
```

## 2. Cloudflare Pages

1. 进入 Cloudflare Dashboard。
2. Workers & Pages -> Create -> Pages -> Upload assets。
3. 上传部署压缩包。
4. 项目名可用 `nuaa-research-progress`。

上线后，学生使用首页链接提交进展，负责人使用 `/admin.html` 管理。

## 3. 注意

V1 为轻量内部系统，后台口令是前端口令。正式长期公开使用时，建议增加登录权限，并把删除/反馈操作限制给负责人账号。
