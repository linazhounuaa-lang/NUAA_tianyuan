# 南京航空航天大学微波光子学实验室 Research Progress 网站

## 页面

- `index.html`：学生提交科研进展。
- `share.html`：文献、软件、算法和资料分享。
- `admin.html`：负责人后台，默认口令为 `progress2026`。
- `publications.html`：公开展示 Google Scholar、个人主页、ORCID 和论文列表。

## 使用流程

1. 学生打开首页，填写本阶段完成内容、关键结果、问题和下一步计划，可直接上传 PPT、Word、PDF、Excel 或 ZIP 附件。
2. 学生提交页下方会显示“组内进展墙”，组内成员可以互相查看文字进展，但不会显示或下载彼此上传的附件。
3. 负责人进入后台查看所有提交记录，可搜索、按方向筛选、下载附件、标记已读、写反馈、删除误提交。
4. 负责人在后台维护学术主页信息和论文列表。
5. 公开页 `publications.html` 自动展示主页链接、科研项目、研究方向可视化和论文条目。
6. 公开页 `share.html` 可由组内成员上传文献、软件、算法或代码，大家都可以下载。

## 口令

- 进展提交页组内口令：`nuaa2026`。
- 负责人后台口令：`progress2026`。

## 负责人如何添加内容

- 打开 `admin.html`，输入后台口令 `progress2026`。
- 在“科研项目”区域点击“新增项目”，可以添加国家自然科学基金、人才项目、校内启动基金等。
- 在“论文列表”区域点击“新增论文”，可以添加论文题目、作者、期刊、年份、DOI 和链接。
- 在“学术主页信息”区域可以修改姓名、职务、邮箱、Google Scholar、个人主页和简介。

## 附件上传

- 学生可以直接选择本地文件上传，单个文件建议不超过 50 MB。
- 后台记录里会显示附件名称和下载链接，负责人点击即可下载。
- 学生页面会展示其他人的文字进展，但不会展示附件下载链接。
- 文献分享页是公开共享页面，上传的文件和链接会给组内成员下载。
- 当前版本没有学生账号登录；附件链接如果被转发，拿到链接的人也可能打开。未发表论文、敏感数据或保密材料建议先不要上传，或后续升级为账号登录权限版本。

## 本地预览

```bash
node preview-server.js
```

然后访问 `http://127.0.0.1:8777/`。

## 云端数据库

当前代码支持 Supabase。填写 `config.js` 后会优先保存到云端；未填写时使用当前浏览器本地缓存。

建库时在 Supabase SQL Editor 中执行 `schema.sql`。该脚本会同时创建进展表、论文表、项目表和附件存储桶。
