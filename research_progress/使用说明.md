# 南京航空航天大学微波光子学实验室 Research Progress 网站

## 页面

- `index.html`：学生提交科研进展。
- `admin.html`：负责人后台，默认口令为 `progress2026`。
- `publications.html`：公开展示 Google Scholar、个人主页、ORCID 和论文列表。

## 使用流程

1. 学生打开首页，填写本阶段完成内容、关键结果、问题和下一步计划。
2. 负责人进入后台查看所有提交记录，可搜索、按方向筛选、标记已读、写反馈、删除误提交。
3. 负责人在后台维护学术主页信息和论文列表。
4. 公开页 `publications.html` 自动展示主页链接和论文条目。

## 本地预览

```bash
node preview-server.js
```

然后访问 `http://127.0.0.1:8777/`。

## 云端数据库

当前代码支持 Supabase。填写 `config.js` 后会优先保存到云端；未填写时使用当前浏览器本地缓存。

建库时在 Supabase SQL Editor 中执行 `schema.sql`。
